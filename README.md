Chronos is a comprehensive PyQt6 desktop application engineered to harmonize the dual demands of intensive academic life and independent business operations. Designed specifically for the rigorous environment of an Information Systems undergraduate track, the application effortlessly handles complex study schedules, coding assignments, and cybersecurity research hours.

Beyond campus life, Chronos serves as the ultimate command center for managing technical support operations. The dashboard provides robust integrated tools to track client service packages, manage hardware maintenance appointments, and monitor the financial cashflow generated from system configurations and website development projects. By unifying task management, schedule tracking, detailed note-taking, and income logging into a single offline interface, this suite ensures that both university deadlines and entrepreneurial workflows are executed with absolute precision.
